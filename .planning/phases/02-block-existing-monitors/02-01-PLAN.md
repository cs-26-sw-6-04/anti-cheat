<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test process → kernel LSM hook | Attacker child crosses into kernel space via ptrace/process_vm_* syscalls; LSM hook is the enforcement point |
| test harness → ring buffer | Deny event crosses from kernel ring buffer to userspace AC session; event loss would make BLOCK-02 undetectable |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Spoofing | tests/block.cpp attack lambda | mitigate | Use `targets::flag_secret()` for target creation — produces a fresh randomized token per run, preventing false positives from stale state |
| T-02-02 | Tampering | ring buffer overflow during test | accept | Tests run serially (RUN_SERIAL TRUE in CMakeLists.txt); event volume is minimal (one event per test); overflow is not a realistic risk in this context |
| T-02-03 | Repudiation | BPF LSM not active (unprivileged run) | mitigate | `session::open_or_skip()` (called inside `run_scenario`) skips gracefully with "skipping live BPF test:" message; SKIP_REGULAR_EXPRESSION in CMakeLists.txt suppresses false failures |
</threat_model>
